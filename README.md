# SteuerCockpit

Lokale, offline nutzbare Steuer-App als erster Prototyp fuer:

- Einnahmen- und Ausgabentracking
- Fahrtenbuch mit Plausibilitaetscheck
- EUR-Vorbereitung nach Kategorien
- UStVA-Vorbereitung mit Quartalswerten, Umsatzsteuer, Vorsteuer und Zahllast
- Getrennte Taetigkeiten, z. B. gewerblich und freiberuflich
- Ruecklagen fuer erwartete Steuerzahlungen
- Automatische Steuerhinweise fuer offensichtliche Pruefpunkte wie Belege, Vorsteuer, Bewirtung, Fahrtenbuch, Privatanteile, groessere Anschaffungen und Ruecklagen
- CSV-Export und JSON-Backup

## GitHub Pages

Nach Aktivierung von GitHub Pages ist die App erreichbar unter:

https://renevogel1989-create.github.io/Steuercockpit/

Die Steuerdaten werden nicht ins Repository geschrieben. Sie bleiben im LocalStorage des jeweiligen Browsers.

## Android

Die App in Chrome oeffnen und ueber das Menue als App installieren bzw. zum Startbildschirm hinzufuegen.

## Wichtiger Hinweis

Die App ersetzt keine Steuerberatung und uebermittelt keine Daten an ELSTER. Sie hilft beim Sammeln, Sortieren und Plausibilisieren deiner Unterlagen.
